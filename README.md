# Sheebase Board — прототип совместной онлайн-доски

Рабочий прототип «бесконечной» доски для совместной визуальной работы по образцу Miro: стикеры, фигуры, коннекторы, фреймы, рисование и редактирование в реальном времени несколькими участниками.

Технические требования, анализ референса и архитектура описаны в [docs/REQUIREMENTS.md](docs/REQUIREMENTS.md).

## Возможности

- **Дашборд**: список досок, поиск, создание из шаблонов (пустая, ретроспектива, канбан, брейншторм, майнд-мэп), переименование, дублирование, удаление.
- **Холст**: бесконечный, точечная сетка, масштаб 10–400% (Ctrl/⌘ + колесо, pinch, кнопки), панорамирование (колесо, пробел, средняя кнопка, «Рука»), мини-карта, «вписать всё».
- **Объекты**: стикеры с автоподбором размера шрифта, 8 фигур с текстом, текстовые блоки, коннекторы (прямые, ломаные, кривые; привязка к объектам, стрелки, подписи), перо и ластик, фреймы (двигают своё содержимое), изображения (загрузка, вставка из буфера, drag&drop).
- **Редактирование**: выделение кликом/рамкой, перемещение с умными направляющими, изменение размера (в т. ч. группы), контекстная панель свойств, слои, группировка, блокировка, дублирование, копирование/вставка между вкладками и досками, кнопки «+» для быстрого создания связанных объектов (как в Miro), undo/redo.
- **Совместная работа**: мгновенная синхронизация (включая промежуточные состояния при перетаскивании), курсоры и выделения участников, аватары присутствия, слияние конкурентных изменений на уровне полей, работа без сети с досылкой изменений после переподключения.
- **Экспорт**: PNG, SVG, JSON-бэкап и импорт JSON.

## Быстрый старт

Требуется Node.js ≥ 20.

```bash
npm install
npm run build
npm start
```

Откройте http://localhost:3000. Чтобы проверить совместную работу, откройте ту же доску во втором окне (или на другом устройстве в той же сети) — ссылку копирует кнопка «Поделиться».

Переменные окружения: `PORT` (по умолчанию 3000), `DATA_DIR` (по умолчанию `./data`).

### Режим разработки

```bash
npm run dev
```

Vite с горячей перезагрузкой — http://localhost:5173 (запросы `/api` и `/ws` проксируются на сервер :3000, сервер перезапускается при изменениях).

## Тесты

```bash
npm test
```

```bash
npm run build
npm run e2e
```

- `npm test` — юнит- и интеграционные тесты (Vitest): операции, геометрия, валидация, история undo/redo, рандомизированный тест сходимости алгоритма синхронизации (300 сценариев), REST API и WebSocket-комнаты сервера, сохранение между перезапусками.
- `npm run e2e` — сценарий в настоящем браузере (Playwright, Chromium) с двумя участниками на одной доске: создание объектов, синхронизация, коннекторы, фреймы, undo/redo, буфер обмена, экспорт PNG, работа без сети и перезапуск сервера. Нужен пакет `playwright` с Chromium (`npm i -D playwright && npx playwright install chromium`, если его нет в системе). Скриншоты сохраняются в `e2e/artifacts/`.

## Архитектура

```
src/
  shared/      модель данных, операции (applyOps), геометрия, валидация, шаблоны — общие для клиента и сервера
  server/      Express (REST + статика), ws (WebSocket-комнаты), файловое хранилище досок
  client/
    pages/     дашборд
    board/     холст, взаимодействия, оверлей, панели, контроллер (история + синхронизация), экспорт
tests/         Vitest
e2e/           Playwright-сценарий
docs/          технические требования
```

**Синхронизация.** Клиент применяет свои изменения сразу (оптимистично), пакетирует их (~30 мс) и отправляет на сервер с порядковым номером. Сервер применяет пакеты строго в порядке поступления, рассылает их остальным и подтверждает отправителю. Пока изменение поля не подтверждено, клиент игнорирует чужие изменения этого поля — сервер всё равно применит наше позже. Так все клиенты сходятся к состоянию сервера, а одновременные изменения разных полей одного объекта не теряются. Подробнее — раздел 7 требований.

**Рендеринг.** Объекты — DOM-элементы и SVG внутри контейнера с CSS-трансформацией камеры; при движении перерисовываются только изменённые объекты. Рамки выделения, маркеры и курсоры рисуются в экранных координатах поверх холста. Раскладка текста считается через `canvas.measureText` — одинаково для отображения и экспорта.

## Ограничения прототипа

Нет аутентификации и прав доступа (доступ по ссылке), комментариев, голосования, таймера, видео, истории версий, поворота объектов; сервер — один процесс с файловым хранилищем. Полный список — раздел 8 требований.

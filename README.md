## Быстрый старт

Требуется Node.js ≥ 20.

```bash
npm install
npm run build
npm start
```

Откройте http://localhost:3000. Чтобы проверить совместную работу, откройте ту же доску во втором окне или на другом устройстве в той же сети. Ссылку копирует кнопка «Поделиться».

Режим разработки: Vite с горячей перезагрузкой на http://localhost:5173, запросы `/api` и `/ws` проксируются на сервер :3000.

```bash
npm run dev
```

## Полная опись функционала

Пометка **(v0.2)** — функция добавлена во второй итерации.

### 1. Дашборд досок

Стартовая страница (`#/`).

| Функция | Как работает |
|---|---|
| Создание доски | Карточки шаблонов: «Пустая доска», «Ретроспектива», «Канбан», «Брейншторм», «Майнд-мэп». Клик создаёт доску и открывает её. Имя по умолчанию — название шаблона или «Новая доска» |
| Список досок | Все доски сервера, новые сверху. Карточка: миниатюра, название, дата («сегодня, 14:05» или «12 нояб. 2026 г.»), число объектов с русским склонением |
| Миниатюры **(v0.2)** | Упрощённое SVG-изображение содержимого: фреймы, стикеры цветом, фигуры контуром, текст полосками, линии. Генерирует сервер, браузер кеширует до изменения доски. У пустой доски — первая буква названия |
| Поиск | Фильтр по подстроке в названии, без учёта регистра |
| Переименование | Меню «⋯» → «Переименовать»: поле в карточке. Enter или потеря фокуса — сохранить, Esc — отменить |
| Дублирование | Меню «⋯» → «Дублировать»: копия объектов, имя «<название> (копия)» |
| Удаление | Меню «⋯» → «Удалить» с подтверждением. Участники, у которых доска открыта, видят «Доска удалена». Версии доски удаляются вместе с ней |
| Профиль | В шапке: аватар, имя, выбор из 10 цветов |
| Ошибки | «Сервер недоступен. Проверьте, что он запущен.» |

### 2. Холст и навигация

| Функция | Как работает |
|---|---|
| Бесконечный холст | Координаты без ограничений (валидация до ±10 000 000). Точечная сетка с шагом 24 единицы, при масштабе меньше 30% скрывается |
| Масштаб | 10–400%. Ctrl/⌘ + колесо и pinch на тачпаде — к точке под курсором. Кнопки «−»/«+» (×1,25), клавиши `+`/`-`, Ctrl/⌘ + `=`/`-`. Клик по проценту — 100% |
| Pinch на сенсорном экране | Два пальца масштабируют и сдвигают вид. Прерванный браузером жест откатывается |
| Панорамирование | Колесо или тачпад (Shift + колесо — по горизонтали), Пробел + перетаскивание, средняя кнопка мыши, инструмент «Рука» (H) |
| Вписать всё / 100% / к выделению | Shift+1 (не больше 100%) / Shift+0 или Ctrl+0 / Shift+2 (не больше 200%). Кнопка ⛶ — вписать всё |
| Мини-карта | 200×130 px в правом нижнем углу: объекты и рамка видимой области. Клик и перетаскивание переносят вид (линейно, без «убегания»). Скрывается кнопкой и в меню «Вид», на экранах уже 720 px не показывается |
| Память вида | Положение и масштаб для каждой доски сохраняются в браузере. При первом открытии вид вписывается в содержимое |

### 3. Инструменты

Левая вертикальная панель. После создания объекта инструмент возвращается к «Выбору», кроме пера и ластика. Во время голосования доступны только «Выбор» и «Рука».

| Инструмент | Клавиша | Поведение | Доп. настройки |
|---|---|---|---|
| Выбор | V | Выделение, перемещение, изменение размера | — |
| Рука | H | Перетаскивание сдвигает вид | — |
| Стикер | N | Клик ставит стикер 200×200 и открывает ввод | 10 цветов |
| Текст | T | Клик создаёт текстовый блок и открывает ввод | — |
| Фигуры | S (R — прямоугольник, O — эллипс) | Клик — 200×200, протягивание — свой размер (Shift — квадрат/круг). Сразу открывается ввод | 8 видов фигур |
| Коннектор | L | Протягивание от объекта к объекту или в пустое место. Цель подсвечивается | Прямая / ломаная / кривая |
| Перо | P | Свободное рисование со сглаживанием | 14 цветов, толщина 2/4/8/14 |
| Ластик | E | Удаляет штрихи пера, которых касается | — |
| Фрейм | F | Клик — 800×600, протягивание — свой размер. Имя «Фрейм N» | — |
| Комментарий **(v0.2)** | C | Клик по объекту (комментарий привязывается к нему) или по холсту — новое обсуждение | — |
| Изображение | — | Выбор файла с диска | — |
| Шаблоны **(v0.2)** | — | Вставка шаблона в центр экрана (см. [раздел 22](#22-шаблоны)) | — |
| Фреймы и презентация **(v0.2)** | — | Открывает панель фреймов (см. [раздел 18](#18-фреймы-и-режим-презентации)) | — |
| Отменить / Повторить | Ctrl+Z / Ctrl+Shift+Z | Кнопки внизу панели. Если открыт ввод текста, он сначала завершается | — |

### 4. Объекты и их свойства

| Тип | Свойства | Особенности |
|---|---|---|
| **Стикер** | Цвет (10), текст, ссылка, автор **(v0.2)** | 200×200. Размер шрифта подбирается автоматически: максимальный, при котором текст помещается, целые слова не разрываются. Изменение размера — пропорциональное. Имя автора выводится внизу, если включено в меню «Вид» |
| **Фигура** | Вид (прямоугольник, скруглённый, эллипс, треугольник, ромб, параллелограмм, шестиугольник, звезда), заливка (16 цветов, включая «без заливки»), цвет и толщина обводки (1–8), текст, размер и цвет текста, ссылка | Текст центрируется во вписанной области и уменьшается, если не помещается. 8 маркеров размера |
| **Текст** | Текст, размер шрифта (10–120), цвет, жирный, выравнивание, ссылка | Ширина 320 по умолчанию, высота по содержимому. Боковые маркеры меняют ширину, угловые масштабируют шрифт. Пустой блок удаляется после ввода вместе с привязанными коннекторами |
| **Коннектор** | Стиль (прямой, ломаный, кривой), цвет, толщина (1–8), стрелки в начале и в конце, подпись (до 500 символов) | Концы привязываются к объектам (сторона выбирается автоматически) или свободны. Привязанный конец следует за объектом, концы можно переподключать. Удаляется вместе с объектом |
| **Штрих пера** | Цвет, толщина | Точки упрощаются (Рамер — Дуглас — Пекер) и сглаживаются |
| **Фрейм** | Заголовок (до 500 символов), заливка, ссылка | Рисуется под остальными объектами, заголовок постоянного экранного размера. Перемещение и выравнивание фрейма переносят всё, что целиком лежит внутри |
| **Изображение** | Ссылка | PNG, JPEG, GIF, WebP, SVG: загрузка кнопкой, вставка из буфера, перетаскивание файлов (до 10). Картинки больше 1600 px уменьшаются (кроме GIF и SVG), на доске — не больше 480 единиц. Изменение размера — пропорциональное |

**Ссылка на объекте (v0.2).** Кнопка «Ссылка» в контекстной панели. Адрес без схемы дополняется `https://`, другие схемы (`javascript:`, `mailto:` и т. п.) отклоняются. На объекте появляется значок ↗ в правом верхнем углу, клик по нему открывает адрес в новой вкладке (`noopener`, `noreferrer`).

Порядок отрисовки: фреймы → остальные объекты по слою → коннекторы.

### 5. Выделение и манипуляции

| Функция | Как работает |
|---|---|
| Выделение | Клик. Shift+клик добавляет или убирает. Рамка по пустому месту (и по пустой области фрейма) выделяет пересечённые объекты, фреймы — только целиком попавшие. Фрейм выделяется кликом по заголовку или пустой области. Ctrl/⌘+A — всё, Esc — снять |
| Перемещение | Перетаскивание (порог 4 px) или стрелки (1 единица, с Shift — 10). Фрейм переносит содержимое в обоих случаях. Свободные концы выделенных коннекторов сдвигаются вместе с выделением |
| Умные направляющие | Края и центры выделения притягиваются (порог 6 px) к соседним видимым объектам, рисуются розовые линии. Alt — без привязки |
| Изменение размера | Стикер и изображение — 4 угловых маркера (пропорционально). Текст — 4 угловых (масштаб шрифта) и 2 боковых (ширина). Фигура, фрейм и штрих — 8 (Shift — пропорционально). Несколько объектов — пропорционально всей группой |
| Быстрое создание «+» | Кнопки «+» по сторонам одиночного стикера, фигуры, текста или изображения. Клик создаёт копию того же вида (у изображения — стикер) с пустым текстом в 100 единицах, обходя занятые места, соединяет стрелкой и открывает ввод. Перетаскивание от «+» проводит коннектор |
| Новый стикер | Двойной клик по пустому месту холста или фрейма |
| Удаление | Delete или Backspace. Заблокированные объекты не удаляются, привязанные коннекторы удаляются вместе с объектом |
| Слои | PageUp — на передний план, PageDown — на задний |
| Группировка | Ctrl/⌘+G, Ctrl/⌘+Shift+G — разгруппировать. Клик по участнику группы выделяет всю группу |
| Блокировка | Ctrl/⌘+Shift+L. Пунктирная рамка. Объект не двигается, не меняет размер, не редактируется и не удаляется, но переезжает вместе с фреймом |
| Отмена жеста | Esc во время перетаскивания, изменения размера, рисования коннектора или работы ластиком. Жест, прерванный браузером, тоже откатывается |

### 6. Выравнивание и распределение

**(v0.2)** Доступно при выделении двух и более незаблокированных объектов: кнопка «Выровнять» в контекстной панели, блок в контекстном меню или клавиши.

| Действие | Клавиши | Как работает |
|---|---|---|
| По левому / правому краю | Alt+A / Alt+D | Край каждого объекта — по краю общей рамки выделения |
| По верхнему / нижнему краю | Alt+W / Alt+S | То же по вертикали |
| По центру / по середине | Alt+H / Alt+V | Центр каждого объекта — по центру общей рамки |
| Распределить по горизонтали / вертикали | Alt+Shift+H / Alt+Shift+V | Для трёх и более объектов: крайние остаются на месте, промежутки между остальными становятся равными |

Фрейм выравнивается вместе с содержимым. Коннекторы и заблокированные объекты не участвуют. Одна команда — один шаг отмены.

### 7. Контекстная панель

Плавающая панель над выделением. Скрывается во время перетаскивания и голосования.

| Выделение | Элементы |
|---|---|
| Любое | Цвет, Дублировать, На передний план, На задний план, Сгруппировать или Разгруппировать, Заблокировать, Удалить |
| 2+ объекта **(v0.2)** | Выровнять и распределить |
| Один стикер, фигура, текст, изображение или фрейм **(v0.2)** | Ссылка: поле адреса, «Сохранить», «Открыть», «Убрать» |
| Фигура | Вид фигуры, цвет и толщина обводки, размер шрифта, цвет текста |
| Текст | Размер шрифта, жирный, выравнивание |
| Коннектор | Толщина, стиль линии, стрелки в начале и в конце |
| Штрих пера | Толщина |
| Только заблокированные | «Разблокировать» |

### 8. Контекстное меню

**(v0.2)** Правый клик (или долгое нажатие на сенсорном экране). Клик по объекту выделяет его, если он ещё не выделен.

| Где | Пункты |
|---|---|
| По объекту | Копировать, Вырезать, Вставить, Дублировать · На передний план, На задний план · Сгруппировать / Разгруппировать · Заблокировать / Разблокировать · Выровнять и распределить (2+) · Добавить комментарий · Экспорт выделения в PNG · Удалить |
| По пустому месту | Вставить (в точку клика), Добавить стикер здесь, Добавить комментарий здесь · Выделить всё, Вписать всё, Найти на доске |

Копирование из меню пишет в системный буфер и во внутренний. Вставка читает системный буфер, а если браузер не разрешает — внутренний. Меню закрывается кликом вне его, Esc или колесом мыши.

### 9. Редактирование текста

| Функция | Как работает |
|---|---|
| Начать | Двойной клик или Enter. Новый стикер, текст и фигура открываются для ввода сразу |
| Что редактируется | Стикер, фигура, текст — содержимое; коннектор — подпись; фрейм — заголовок |
| Завершить | Esc, Ctrl/⌘+Enter или клик вне объекта |
| Вставка | Только простой текст |
| Синхронизация | Текст уходит участникам по мере ввода |
| Защита от одновременного ввода **(v0.2)** | Под объектом, который редактирует коллега, — плашка «✎ Имя». Начать ввод в нём нельзя, появляется подсказка «Сейчас редактирует …» |
| Лимиты | Текст — 20 000 символов, подпись и заголовок — 500. При превышении ввод обрезается с подсказкой |
| История | Создание объекта и ввод текста — один шаг отмены. Брошенный пустой текст не оставляет следа |

### 10. Буфер обмена и дублирование

| Функция | Как работает |
|---|---|
| Копировать / вырезать | Ctrl/⌘+C / X: в системный буфер кладётся JSON `sheebase/items` — выделение, содержимое выделенных фреймов и коннекторы между ними |
| Вставить | Ctrl/⌘+V: объекты Sheebase — с новыми идентификаторами в позицию курсора (между вкладками и досками). Изображение — как изображение. Простой текст — как стикер (до 5000 символов) |
| Дублировать | Ctrl/⌘+D — копия со сдвигом на 30 единиц |
| Коннекторы | Между копируемыми объектами привязываются к копиям. Концы, привязанные к объектам вне копии, становятся свободными |

### 11. История действий

| Функция | Как работает |
|---|---|
| Отмена и повтор | Ctrl/⌘+Z, Ctrl/⌘+Shift+Z или Ctrl/⌘+Y, кнопки на панели. Глубина — 300 шагов |
| Шаг | Одно перетаскивание, изменение размера, рисование коннектора, проход ластиком, создание объекта вместе с вводом текста, любая команда (удаление, вставка, выравнивание, вставка шаблона и т. д.) |
| Чьи действия | Только свои. Отмена отправляется участникам как обычное изменение |
| Восстановление версии | Очищает историю: она ссылалась на прежнее состояние доски |

Комментарии, голоса и таймер в историю не входят: это сессионные данные, ими управляет сервер.

### 12. Совместная работа и присутствие

| Функция | Как работает |
|---|---|
| Синхронизация | Изменения, включая промежуточные состояния перетаскивания и ввод текста, пакетируются по 30 мс и рассылаются всем |
| Курсоры | Курсоры участников с именем и цветом, до 25 обновлений в секунду |
| Выделения участников | Объекты, выделенные коллегами, обводятся их цветом с подписью |
| Присутствие | Аватары в шапке (до 6 и «+N»). Меню аватара: «Следовать за видом», «Перейти к курсору» |
| Профиль на лету **(v0.2)** | Новые имя и цвет сразу видны коллегам (аватар, курсор, подписи) |
| Статус соединения | Онлайн, подключение, офлайн (клик — переподключиться сейчас), ошибка |
| Конфликты | LWW по отдельным полям в порядке сервера: одновременные изменения разных полей одного объекта сохраняются. Клиенты гарантированно сходятся к состоянию сервера |
| Работа без сети | Правки работают локально и уходят после переподключения (повтор 0,5 → 10 с). Переименование без сети не теряется |
| Коррекция | Если сервер отбросил часть данных, автор получает актуальное состояние объектов |
| Поделиться | Кнопка копирует ссылку на доску |
| Закрытие вкладки | Неотправленные правки досылаются |

### 14. Комментарии

**(v0.2)** Обсуждения, не загромождающие доску. Не попадают в экспорт, выделение и историю отмены.

| Функция | Как работает |
|---|---|
| Создать | Инструмент C, пункт контекстного меню или «Добавить комментарий» по объекту. Комментарий на объекте привязывается к нему и следует за ним, на холсте — остаётся на месте |
| Ввод | Enter — отправить, Shift+Enter — перенос строки, Esc — отменить. 1–2000 символов |
| Пины | Значок с инициалом автора, числом сообщений и красной точкой «непрочитано». Постоянного размера при любом масштабе |
| Тред | Клик по пину открывает карточку: сообщения (автор, «5 мин назад»), поле ответа, «Отметить как решённое» / «Открыть снова», удаление обсуждения (с подтверждением), удаление своих сообщений. Удаление первого сообщения удаляет весь тред |
| Панель комментариев | Кнопка со счётчиком открытых тредов в шапке. Вкладки «Открытые» / «Решённые», клик переносит вид к пину и открывает тред |
| Решённые | Пины решённых тредов скрыты, пока не включено «Показывать решённые комментарии» в меню «Вид» |
| Непрочитанные | Тред непрочитан, если в нём появилось чужое сообщение после вашего последнего просмотра. Отметки хранятся в браузере |
| Удаление объекта | Привязанный тред остаётся на последнем месте объекта |
| Автор и время | Ставятся сервером, подделать нельзя |

### 15. Голосование

**(v0.2)** Приоритизация идей, как в ретро.

| Функция | Как работает |
|---|---|
| Запуск | Кнопка голосования в шапке: число голосов на участника (1–10), «Начать голосование». Голосование видят все участники |
| Режим голосования | Клик по стикеру, фигуре, тексту или изображению — голос (за один объект можно отдать несколько). Alt+клик — снять голос. Перетаскивание по холсту сдвигает вид. Редактирование, инструменты и правый клик недоступны |
| Баннер | «Осталось X из N голосов · проголосовали: K» и «Завершить» |
| Тайность | Свои голоса видны на бейджах. Чужие голоса сервер не передаёт до завершения: нельзя подстроиться под других |
| Итоги | После «Завершить» у всех открывается панель итогов: объекты по убыванию голосов с полосами. Клик переносит к объекту, на объектах — оранжевые бейджи с суммой. «Очистить результаты» убирает голосование |
| Несколько вкладок | Голоса привязаны к профилю, а не к вкладке: лимит общий |

### 16. Таймер

| Функция | Как работает |

**(v0.2)**

| Функция | Как работает |

### 19. История версий

**(v0.2)** Защита от ошибок и «вандализма»: undo отменяет только свои действия, версии откатывают всю доску.

| Функция | Как работает |
|---|---|
| Панель | Кнопка с часами в шапке: список версий (название, «5 мин назад», число объектов, пометка «авто») |
| Ручная версия | Поле названия и «Сохранить» (без названия — «Версия от <дата>») |
| Автоматические версии | Перед первой правкой после 10 минут без изменений (и при первой правке новой доски) сохраняется состояние до этой серии правок |
| Предпросмотр | Клик по версии — изображение доски в этой версии |
| Восстановление | С подтверждением. Текущее состояние сначала сохраняется версией «Перед восстановлением «…»», поэтому восстановление тоже можно откатить. Все участники сразу получают восстановленную доску, их неотправленные правки применяются поверх |
| Удаление версии | Кнопка в предпросмотре |
| Хранение | Не больше 50 автоматических и 100 ручных версий на доску (старые удаляются). Версии удаляются вместе с доской |

### 20. Хранение данных

| Функция | Как работает |
|---|---|
| Доска | `DATA_DIR/boards/<id>.json`: `{meta, items, comments, session}`. Файлы версии 0.1 без `comments` и `session` читаются |
| Версии **(v0.2)** | `DATA_DIR/versions/<boardId>/index.json` и `<versionId>.json` |
| Автосохранение | Отложенная запись через 300 мс после изменения, в том числе комментариев, таймера и голосования |
| Надёжность | Атомарная запись (временный файл + rename). Повреждённые файлы пропускаются, объекты повторно проверяются. При SIGINT/SIGTERM несохранённое записывается |

### 26. Протокол WebSocket

Путь `/ws`, сообщения — JSON. Первое сообщение клиента — `hello`.

| Направление | Сообщение | Назначение |
|---|---|---|
| C→S | `{t:'hello', boardId, user:{id,name,color}}` | Вход на доску |
| C→S | `{t:'ops', seq, ops:[…]}` | Пакет операций `add` / `update` / `delete` |
| C→S | `{t:'cursor', x, y}` | Курсор (`null` — ушёл с холста) |
| C→S | `{t:'selection', ids, editing}` | Выделение и редактируемый объект (`editing` — v0.2) |
| C→S | `{t:'rename', name}` | Переименование доски |
| C→S **(v0.2)** | `{t:'user', user:{name,color}}` | Обновление профиля |
| C→S **(v0.2)** | `{t:'view', rect:{x,y,w,h}}` | Видимая область (для следования) |
| C→S **(v0.2)** | `{t:'summon'}` | «Собрать всех ко мне» |
| C→S **(v0.2)** | `{t:'timer', action:'start'\|'pause'\|'resume'\|'add'\|'reset', durationMs?, deltaMs?}` | Таймер |
| C→S **(v0.2)** | `{t:'voting', action:'start'\|'end'\|'clear', votesPerUser?}`, `{t:'vote', itemId, delta:±1}` | Голосование |
| C→S **(v0.2)** | `{t:'comment', action:'create'\|'reply'\|'resolve'\|'deleteMessage'\|'delete', …}` | Комментарии |
| S→C | `{t:'init', meta, items, peers, clientId, comments, session, now}` | Снимок доски. У `peers` — `view`, `selection`, `editing` (v0.2) |
| S→C | `{t:'ack', seq}` | Пакет применён |
| S→C | `{t:'ops', from, ops}` | Операции других участников или коррекция от `server` |
| S→C | `{t:'join', peer}` / `{t:'leave', clientId}` / `{t:'peer', peer}` (v0.2) | Присутствие |
| S→C | `{t:'cursor', …}` / `{t:'selection', …}` / `{t:'view', from, rect}` (v0.2) / `{t:'summon', from}` (v0.2) | Курсоры, выделения, вид, призыв |
| S→C **(v0.2)** | `{t:'session', session, now}` | Таймер и голосование — индивидуально каждому участнику (только свои голоса) |
| S→C **(v0.2)** | `{t:'thread', thread}` / `{t:'thread-delete', id}` | Комментарии |
| S→C **(v0.2)** | `{t:'reset', items, reason}` | Доска восстановлена из версии |
| S→C | `{t:'meta', meta}` / `{t:'notice', message}` (v0.2) / `{t:'error', code, message}` | Метаданные, подсказки, ошибки (`not_found`, `deleted`, `bad_request`) |

Соединения проверяются ping/pong каждые 30 с.

### 27. Лимиты и валидация

Сервер проверяет каждую операцию и каждое сессионное действие: типы, обязательные поля, диапазоны. Неизвестные поля отбрасываются.

| Параметр | Значение |
|---|---|

| Подпись коннектора, заголовок фрейма | 500 символов |
| Имя доски / имя участника | 120 / 40 символов |
| Цвет **(v0.2)** | только `#rgb[a]`, `#rrggbb[aa]`, `transparent`, имя цвета, `rgb()/rgba()` |
| Ссылка **(v0.2)** | `http(s)://`, до 2000 символов, без пробелов и кавычек |
| Автор стикера **(v0.2)** | до 60 символов |
| Комментарий **(v0.2)** | 1–2000 символов, до 500 сообщений в треде |
| Таймер **(v0.2)** | 5 с – 3 ч, «+время» до ±1 ч |
| Голосов на участника **(v0.2)** | 1–99 (в интерфейсе 1–10) |
| Версии **(v0.2)** | 50 автоматических + 100 ручных на доску, автоснимок не чаще раза в 10 минут |
| Изображение (data URL) | 12 МБ, `png/jpeg/gif/webp/svg+xml` в base64 |
| Точек в штрихе | 20 000 |
| Операций в сообщении / размер сообщения | 5 000 / 20 МБ |

## Архитектура

```
src/
  shared/      модель данных, операции (applyOps), геометрия, раскладка (поиск, выравнивание),
               миниатюры, валидация, шаблоны — общие для клиента и сервера
  server/      Express (REST + статика), ws (комнаты), session.ts (таймер, голосование, комментарии),
               repository.ts (доски), versions.ts (снимки)
  client/
    pages/     дашборд
    board/     холст, взаимодействия, оверлей, панели, контроллер (история + синхронизация),
               комментарии, фасилитация, поиск, фреймы и презентация, версии, экспорт
tests/         Vitest
e2e/           Playwright-сценарий
docs/          требования и дизайн итерации 2
```

**Два вида данных.** Объекты доски синхронизируются оптимистично: клиент применяет изменения сразу, пакетирует (~30 мс) и отправляет с порядковым номером. Сервер применяет пакеты строго по порядку и подтверждает. Пока изменение поля не подтверждено, чужие изменения этого поля игнорируются, поэтому клиенты сходятся к состоянию сервера. Комментарии, голоса и таймер (v0.2) — **сервер-авторитетные**: клиент отправляет намерение, сервер проверяет права и лимиты, применяет и рассылает результат. Так не теряются одновременные ответы и голоса, а лимиты нельзя обойти. Подробнее — [REQUIREMENTS.md, раздел 7](docs/REQUIREMENTS.md) и [ITERATION-2.md, раздел 2](docs/ITERATION-2.md).

**Рендеринг.** Объекты — DOM и SVG внутри контейнера с CSS-трансформацией камеры, перерисовываются только изменённые. Рамки, маркеры, курсоры, пины комментариев и бейджи — в экранных координатах поверх холста. Текст раскладывается через `canvas.measureText` — одинаково для отображения и экспорта.

## Ограничения прототипа

- Нет аутентификации и ролей: доступ у всех, у кого есть ссылка. Управлять таймером и голосованием может любой участник.
- Нет поворота объектов, таблиц и карточек, совместного посимвольного редактирования одного текста. Одновременный ввод в один объект блокируется индикатором.
- Нет @упоминаний и уведомлений.
- Изображения хранятся внутри JSON доски.
- Сервер — один процесс с файловым хранилищем.

Бэклог с техническим планом — [ITERATION-2.md, раздел 5](docs/ITERATION-2.md#5-бэклог-следующие-итерации).

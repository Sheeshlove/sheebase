# ADR 0001. Язык и рантайм: TypeScript strict на Node.js 24 LTS

- Статус: принято (решение зафиксировано в docs/SPEC.md, раздел 6.2)
- Дата: 2026-11-12

## Контекст

Проект делает небольшая команда вместе с ИИ-ассистентом. Клиент, сервер, ИИ-конвейер и общие схемы должны разделять типы и валидацию. Yjs и BlockNote живут в экосистеме JavaScript.

## Решение

TypeScript в режиме strict везде: клиент, API, сервер синхронизации, воркер, скрипты оценки и нагрузки. Рантайм — Node.js 24 LTS. Монорепозиторий на pnpm workspaces и Turborepo. Вызовы LLM — обычный HTTP.

## Альтернативы

- Python для ИИ-конвейера: второй язык и второй набор схем, а библиотеки машинного обучения не нужны — модели вызываются по HTTP.
- Go или Rust для сервера: нет общих схем с клиентом и готовой серверной части Yjs.

## Последствия

- Схемы Zod в `packages/shared` используются и клиентом, и сервером.
- Тяжёлые вычисления (раскладка, разбор файлов) выполняются в Node; долгие — в воркере.
- В среде разработки от 2026-11-12 установлен Node 22.23, а не 24: `engines` временно допускает ≥ 22, CI использует `.nvmrc` (24). См. docs/STATUS.md.

# ADR 0002. Редактор документов: BlockNote

- Статус: принято (решение зафиксировано в docs/SPEC.md, раздел 6.2)
- Дата: 2026-11-12

## Контекст

Нужен блочный редактор с совместной работой, стабильными идентификаторами блоков (якоря ссылок, задач и чанков поиска) и серверным преобразованием Markdown и HTML в документ для импорта.

## Решение

BlockNote: `@blocknote/core`, `@blocknote/react`, `@blocknote/shadcn`, `@blocknote/server-util`. Пакеты `@blocknote/xl-*` запрещены (GPL или коммерческая лицензия); проверка — в `pnpm licenses:check`.

## Альтернативы

- Tiptap напрямую: блочную модель, меню и перетаскивание пришлось бы писать самим.
- Lexical, Slate: нет готовой связки с Yjs и серверного преобразования того же уровня.

## Последствия

- Спайк M0.6 подтвердил: id блоков стабильны при записи в Y.Doc, при монтировании редактора и при вставке в середину; `server-util` переводит Markdown в Y.Doc и обратно.
- `server-util` требует jsdom — зависимость только серверных приложений.
- Экспорт в PDF и DOCX из xl-пакетов недоступен; если понадобится — отдельное решение.

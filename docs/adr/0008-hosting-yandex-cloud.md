# ADR 0008. Хостинг: одна ВМ в Yandex Cloud с docker compose

- Статус: принято (решение зафиксировано в docs/SPEC.md, раздел 6.2)
- Дата: 2026-11-12

## Контекст

Пилот рассчитан на десятки команд. Бюджет на облако — 110 000 руб. на проект. Данные пользователей должны храниться в РФ.

## Решение

Prod — одна ВМ Yandex Cloud (4 vCPU, 8–16 ГБ, SSD 100 ГБ) с docker compose: Caddy, статические файлы web, api, collab, worker, PostgreSQL, Valkey. Файлы — Yandex Object Storage. Образы — Yandex Container Registry. CI/CD — GitHub Actions. Резервные копии — `pg_dump` с шифрованием в отдельный бакет.

## Альтернативы

- Управляемая PostgreSQL: надёжнее, но не укладывается в бюджет; остаётся вариантом на будущее.
- Kubernetes: избыточен для одной ВМ.

## Последствия

- Единая точка отказа; смягчается ежедневными копиями и еженедельной проверкой восстановления (NFR-REL-2).
- Вертикальное масштабирование; `extension-redis` у Hocuspocus оставлен на случай второй ВМ.
- Деплой на этапе M0 не настраивался: в CI только проверки.

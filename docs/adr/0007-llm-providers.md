# ADR 0007. Провайдеры LLM: YandexGPT (основной), GigaChat (резервный)

- Статус: принято (решение зафиксировано в docs/SPEC.md, раздел 6.2)
- Дата: 2026-11-12

## Контекст

ИИ-функции должны работать на российских моделях с оплатой в рублях. Тесты и разработка не должны зависеть от ключей и сети.

## Решение

Основной провайдер — YandexGPT 5 Pro и Lite и эмбеддинги Yandex `text-search-doc` и `text-search-query`. Резервный — GigaChat 2. Все вызовы идут через интерфейсы `packages/ai/src/providers`; в разработке и тестах — провайдеры `mock` и `replay`.

## Альтернативы

- Зарубежные провайдеры: исключены требованиями к размещению данных и оплате.
- Собственный хостинг открытых моделей: не по бюджету проекта.

## Последствия

- Живые вызовы допускаются только в `*.live.test.ts` и на staging.
- Ответы кешируются по ключу из провайдера, модели, версии промпта и входа.
- Для GigaChat нужен корневой сертификат (`NODE_EXTRA_CA_CERTS`).
- Ключей в среде разработки нет; спайков с живыми провайдерами на этапе M0 не было.

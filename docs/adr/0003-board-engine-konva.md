# ADR 0003. Доска: собственный движок с отрисовкой через Konva

- Статус: принято (решение зафиксировано в docs/SPEC.md, раздел 6.2)
- Дата: 2026-11-12

## Контекст

Доска — ядро продукта и основа программы для ЭВМ, которую нужно зарегистрировать. Готовые движки либо не подходят по лицензии, либо не дают контроля над моделью данных.

## Решение

Собственный пакет `packages/board-engine` (камера, сцена, отсечение, hit-test, инструменты) без зависимости от React. Отрисовка — Konva, React-обвязка (`react-konva`) — в `apps/web/src/features/board`.

## Альтернативы

- tldraw: лицензия не разрешает использование без водяного знака или платного ключа.
- Excalidraw: стиль и модель данных не подходят, сложно встроить связи с документами.
- Чистый Canvas 2D или WebGL: больше работы без выигрыша на 2 000 элементов.

## Последствия

- Спайк M0.7: без отсечения 14 к/с на 2 000 элементов, с отсечением 56–60 к/с; при обзоре всей доски нужен ещё и уровень детализации (без текста на мелком масштабе). Замеры сделаны без GPU и требуют повтора на эталонном ноутбуке.
- Отсечение и уровень детализации закладываются в M3.2 с самого начала.

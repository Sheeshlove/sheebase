# Гостевой доступ и сайт

> Извлечено из `docs/SPEC.md` (разд. 4.12, 4.14, прил. F). Источник истины — SPEC.md; этот файл не редактируется вручную, идентификаторы требований сохранены.

### 4.12. Гостевой доступ (FR-GUEST)

Обязателен для приёмки этапа 2 Фондом.

| ID | Требование | Приоритет |
|---|---|---|
| FR-GUEST-1 | Кнопка «Гостевой вход» на странице входа и на сайте проекта. Создаётся временный пользователь-гость и **копия** демо-пространства, где он редактор. Срок жизни гостя и копии — 24 ч, затем фоновая задача удаляет их | M |
| FR-GUEST-2 | Демо-пространство (эталон) создаётся сидом `pnpm seed:demo`: 4–6 документов учебного проекта, доска с готовой картой, 15–20 задач в разных статусах, 2 файла для пробного импорта и структурирования. Контент — оригинальный (написан командой или сгенерирован и вычитан), без чужих текстов | M |
| FR-GUEST-3 | Постоянная учётная запись для экспертов Фонда (логин и пароль из переменных окружения): обычный пользователь в отдельной копии демо-пространства, которая сбрасывается к эталону каждую ночь в 03:00 МСК | M |
| FR-GUEST-4 | Лимиты гостя: 3 структурирования, 20 вопросов, без приглашений, без экспорта, загрузка файлов ≤ 5 МБ. Плашка «Гостевой режим: данные удалятся через N ч» и кнопка «Зарегистрироваться» | M |
| FR-GUEST-5 | Защита от злоупотреблений: не более 10 гостевых входов в час с одного IP и не более 200 в сутки всего (настраивается) | M |

### 4.14. Сайт проекта (FR-SITE)

| ID | Требование | Приоритет |
|---|---|---|
| FR-SITE-1 | Отдельное статическое приложение `apps/site` на корневом домене, сервис — на поддомене `app.` | M |
| FR-SITE-2 | На **главной странице**: логотипы Фонда содействия инновациям и Платформы университетского технологического предпринимательства и текст дословно: «Проект реализован при поддержке Фонда содействия инновациям в рамках программы «Студенческий стартап» Платформы университетского технологического предпринимательства федерального проекта «Технологии», входящего в состав национального проекта «Эффективная и конкурентная экономика»». Файлы логотипов кладёт команда в `apps/site/public/logos/` (Claude Code не рисует и не скачивает логотипы, а ставит заглушки с TODO) | M |
| FR-SITE-3 | Содержание: что это и для кого, ключевые возможности (автоструктурирование, поиск, совместная работа), сценарий из заявки, тарифы, кнопки «Попробовать» и «Гостевой вход», контакты, реквизиты ООО | M |
| FR-SITE-4 | Юридические страницы (общие для сайта и сервиса): политика обработки ПД, согласие на обработку ПД (отдельный документ), пользовательское соглашение, уведомление о cookie. Тексты — заготовки с пометкой «Требует проверки юристом» | M |
| FR-SITE-5 | Lighthouse ≥ 90 по производительности и доступности | S |
| FR-SITE-6 | Если сайт делает подрядчик (по смете — 25 000 руб.), FR-SITE-2 и FR-SITE-4 остаются обязательными, а `apps/site` используется как прототип | — |

## Приложение F. Требования к демо-контенту

- Тема — правдоподобный студенческий проект (например, «Сервис бронирования переговорных для кампуса»): паспорт проекта, ТЗ на 10–12 страниц, два протокола встреч, конспект статьи по теме, отчёт по этапу.
- Доска: карта, построенная по ТЗ, схема пользовательского пути, ретро-стикеры.
- Задачи: 15–20, все статусы, связи с блоками ТЗ и элементами доски.
- Файлы для пробы: DOCX на 6–8 страниц и PDF на 4–5 страниц с явными действиями и сроками (чтобы черновики задач были заметны).
- Весь текст оригинальный, без реальных ФИО (кроме вымышленных), без логотипов сторонних организаций.

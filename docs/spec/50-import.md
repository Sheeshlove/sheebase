# Импорт

> Извлечено из `docs/SPEC.md` (разд. 4.8). Источник истины — SPEC.md; этот файл не редактируется вручную, идентификаторы требований сохранены.

### 4.8. Импорт (FR-IMP)

| ID | Требование | Приоритет |
|---|---|---|
| FR-IMP-1 | DOCX → документ: заголовки, абзацы, списки, таблицы, жирный и курсив, ссылки, изображения. Через mammoth → HTML → блоки BlockNote на сервере | M |
| FR-IMP-2 | PDF с текстовым слоем → документ: абзацы, эвристическое определение заголовков по размеру шрифта, номера страниц сохраняются в метаданных блоков (для цитирования «стр. N»). PDF без текстового слоя — понятная ошибка «Похоже, это скан. Распознавание текста пока не поддерживается» | M |
| FR-IMP-3 | Markdown (.md, .markdown, .txt) → документ | M |
| FR-IMP-4 | Архив экспорта Notion (Markdown & CSV, zip): дерево страниц по вложенности папок, очистка суффиксов-идентификаторов из имён, внутренние ссылки между страницами переписываются на новые страницы, CSV баз данных → страница с таблицей, вложения-изображения → S3 | M |
| FR-IMP-5 | Ограничения: файл ≤ 20 МБ (zip ≤ 100 МБ, распакованный ≤ 500 МБ, ≤ 5 000 файлов, защита от path traversal и zip-бомб), документ ≤ 300 страниц. Тип определяется по сигнатуре файла, а не по расширению | M |
| FR-IMP-6 | Импорт — фоновая задача с прогрессом и итоговым отчётом (что импортировано, что пропущено и почему) | M |
| FR-IMP-7 | В диалоге импорта галочка «Сразу структурировать» (запускает FR-AI после импорта) | M |
| FR-IMP-8 | Исходный файл хранится в S3 и доступен для скачивания со страницы документа | S |

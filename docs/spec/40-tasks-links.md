# Задачи, граф связей, сводка

> Извлечено из `docs/SPEC.md` (разд. 4.6, 4.7, 4.11). Источник истины — SPEC.md; этот файл не редактируется вручную, идентификаторы требований сохранены.

### 4.6. Задачи (FR-TASK)

Задачи хранятся в PostgreSQL (не в Yjs): для них важны фильтры, сроки и сводки.

| ID | Требование | Приоритет |
|---|---|---|
| FR-TASK-1 | Поля: номер в пространстве (`Т-12`), название (≤ 200 символов), описание (Markdown, ≤ 20 000 символов), статус, исполнитель (участник пространства), срок (дата), автор, даты создания и закрытия, происхождение (`manual` / `ai`) | M |
| FR-TASK-2 | Статусы фиксированы: `draft` («Черновики от ИИ»), `todo` («К выполнению»), `in_progress` («В работе»), `review` («На проверке»), `done` («Готово»). Колонка черновиков видна, только если в ней есть задачи | M |
| FR-TASK-3 | Канбан пространства: перетаскивание между колонками и внутри колонки (дробные индексы), фильтры по исполнителю, сроку («просрочено», «на этой неделе»), поиск по названию | M |
| FR-TASK-4 | Карточка задачи (боковая панель): правка полей, список связей с источниками и элементами доски, добавление и удаление связи | M |
| FR-TASK-5 | Изменения задач видны другим участникам без перезагрузки (≤ 2 с) | M |
| FR-TASK-6 | Черновики от ИИ: принять (→ `todo`), принять все, отклонить (удаление), правка перед принятием | M |
| FR-TASK-7 | Список «Мои задачи» по всем пространствам | S |
| FR-TASK-8 | Напоминание по email о сроке завтра (ежедневная рассылка в 9:00 МСК, можно отключить) | C |

### 4.7. Граф связей (FR-LINK)

| ID | Требование | Приоритет |
|---|---|---|
| FR-LINK-1 | Универсальная таблица связей между конечными точками: `page`, `block` (страница + id блока), `board_item` (доска + id элемента), `task` | M |
| FR-LINK-2 | Типы связей: `source` (задача или узел основан на фрагменте), `related`, `generated_from` (объект создан ИИ из источника), `mention` | M |
| FR-LINK-3 | Обратные ссылки: на странице — панель «Ссылаются сюда», у блоков и элементов — значки (FR-DOC-7, FR-BOARD-7) | M |
| FR-LINK-4 | Если блок или элемент удалён, связь сохраняется и показывается как «Источник удалён»; ежедневная фоновая задача помечает такие связи `broken_at` | M |
| FR-LINK-5 | Связи учитывают права: пользователь не видит связей на страницы пространств, в которых не состоит (между пространствами связи запрещены в MVP) | M |

### 4.11. Сводка для наблюдателя (FR-OBS)

| ID | Требование | Приоритет |
|---|---|---|
| FR-OBS-1 | Страница «Сводка» пространства (доступна всем ролям): задачи по статусам и исполнителям, просроченные, закрытые за 7 дней, страницы, изменённые за 7 дней (кем и когда), последние прогоны ИИ | M |
| FR-OBS-2 | Наблюдатель по умолчанию попадает в пространство на «Сводку» | S |

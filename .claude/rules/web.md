# Правила для apps/web

- Спецификация: docs/spec/20-editor.md, 30-board.md, 40-tasks-links.md; NFR-UX — docs/spec/90-nfr-infra.md.
- Все строки интерфейса — в `src/i18n/ru.ts`, в компонентах нет русского текста.
- Данные сервера — через TanStack Query; локальное состояние интерфейса — Zustand. Не дублировать серверные данные в сторах.
- Компоненты — shadcn/ui (Radix), иконки — lucide-react. Редактор и доска загружаются лениво (NFR-PERF-2).
- Доступность: управление с клавиатуры, видимый фокус, подписи у кнопок-иконок (NFR-UX).
- Для UI-задач — скриншоты Playwright ключевых состояний, их нужно просмотреть.

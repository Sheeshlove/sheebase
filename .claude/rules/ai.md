# Правила для packages/ai

- Спецификация: docs/spec/60-ai.md.
- Вызовы LLM — только через интерфейсы `src/providers`; остальной код не знает, какой провайдер за ними.
- Промпты — файлы с версией в имени (`extract.v1.md`). Изменение промпта — новая версия. После заморозки для итоговой оценки промпты не менять без человека.
- Ответы кешируются по ключу из провайдера, модели, версии промпта и входа.
- В unit-, int- и e2e-тестах — только `mock` и `replay`. Живые вызовы — только `*.live.test.ts`.
- Эталонную разметку и результаты оценки не выдумывать и не править.

# Правила для packages/db

- Спецификация: раздел 7 в docs/spec/90-nfr-infra.md.
- Миграции генерирует drizzle-kit (`pnpm db:generate`), руками SQL-файлы не пишутся и не правятся.
- Миграции только вперёд; применённые не редактировать — нужна новая миграция.
- Удаление столбцов, таблиц и данных — точка ручного контроля: остановиться и спросить.
- Все id — uuid v7, время — timestamptz, имена — snake_case, перечисления — pgEnum.
- После изменения схемы проверить применение с нуля: `pnpm db:reset && pnpm db:migrate`.

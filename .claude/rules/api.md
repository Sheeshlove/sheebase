# Правила для apps/api

- Спецификация: docs/spec/10-auth-workspaces.md и раздел модуля, который затрагивает маршрут.
- Схемы запроса и ответа — Zod в `packages/shared`, маршрут подключает их через `fastify-type-provider-zod`.
- Права проверяются только функциями `packages/shared/permissions`; на каждый маршрут — негативный тест (403).
- Ошибки — единым форматом с кодом из перечня в `packages/shared`; текст для пользователя формирует клиент.
- Тесты маршрутов — через `app.inject()`, файлы `*.int.test.ts`. Менялось API — обновить OpenAPI.
- SQL в этом приложении не пишется: только репозитории `@shibase/db`.

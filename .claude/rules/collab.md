# Правила для apps/collab и packages/doc-model

- Спецификация: docs/spec/20-editor.md (8.3), 30-board.md.
- Структуру Y.Doc читает и меняет только `packages/doc-model`; имена фрагментов и ключей — константы оттуда.
- Изменение структуры Y.Doc — это миграция схемы документа с номером версии и тестом на старых данных.
- `doc-model` изоморфен: без Node API и DOM (проверяет ESLint).
- Сервер не доверяет клиенту: токен, роль и режим только чтения проверяются в хуках Hocuspocus.

# Правила для packages/search

- Спецификация: docs/spec/70-search.md. Замеры и открытая проблема векторной ветки — tools/spikes/README.md (M0.8).
- Каждый запрос фильтруется по `workspace_id` и правам; тест изоляции между пространствами обязателен для любого изменения запроса.
- SQL разрешён только в `src/query.ts` (гибридный запрос); остальное — через `@shibase/db`.
- Параметры RRF и пороги — настройки с тестами, а не константы в коде запроса.
- `qrels.jsonl` и эталонные запросы не редактировать.

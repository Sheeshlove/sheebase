---
name: new-migration
description: Изменить схему БД и сгенерировать миграцию drizzle-kit.
---

1. Измени схему в `packages/db/src/schema/*.ts`.
2. Изменение деструктивное (удаление столбца, таблицы, данных) — остановись и спроси человека.
3. `pnpm db:generate` — миграцию создаёт drizzle-kit; SQL руками не править.
4. `pnpm db:reset && pnpm db:migrate` — миграции применяются с нуля.
5. Обнови репозитории и их интеграционные тесты, затем `pnpm verify`.
6. Применённые ранее миграции не трогать.
